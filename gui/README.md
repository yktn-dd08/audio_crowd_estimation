# 音声・軌跡 同期プレイヤー

Jupyter Notebook / JupyterLab から、波形・スペクトログラム・全軌跡を表示し、音声に合わせて再生バーと現在位置を動かします。ブラウザ内で処理するため、再生中にPythonとの通信は発生しません。外部CDNへの接続も不要です。

## Notebookで使う

リポジトリのルートからNotebookを起動してください。Notebook用の追加依存は `IPython` のみです（通常Jupyterに含まれます）。

```python
from gui import SyncPlayer

player = SyncPlayer(
    audio_path="/path/to/audio.wav",
    trajectory_path="/path/to/trajectory.csv",
    height=900,
)
player  # セルの最後に置くと表示
```

あるいは、画面上のファイル選択から手元PCのファイルを読み込めます。サーバー上のファイルを選ぶ場合は、下記のサーバー用モードを使ってください。

```python
from gui import show_sync_player
show_sync_player();
```

### SSH接続先・サーバー上のファイルをGUIで選ぶ

Notebookのカーネルが動くサーバーのフォルダをたどれる、専用の選択パネルを使えます。初回のみNotebookのセルで依存をインストールしてください。

```python
%pip install "ipywidgets>=8,<9"
```

必要に応じてカーネルを再起動してから実行します。

```python
from gui import show_sync_player

browser = show_sync_player(server_files=True);
# 開始フォルダを指定する場合:
# browser = show_sync_player(server_files=True, start_dir="/data/datasets");
```

1. 「サーバーの音声ファイルを選択」を開き、フォルダを選んで「フォルダを開く / 選択」を押して移動します。
2. 音声ファイルを選択し、同じボタンで確定します。
3. 「サーバーの軌跡CSVを選択」でCSVも確定します。音声とCSVは別のフォルダでも構いません。
4. 「選択した2ファイルを読み込む」を押すと、その下に同期プレイヤーを表示します。

初期フォルダはカーネルの作業フォルダです。「上のフォルダ」で上位へ移動でき、フォルダ欄にパスを入力して「移動」もできます。アクセスできるのはカーネルの実行ユーザーが読み取れるファイルです。追加のHTTPサーバーやSSH転送ポート、手元PCへの事前コピーは不要です。選択したデータはJupyterの接続経由でプレイヤーに渡します。

このモードは生きたNotebookカーネルが必要です。単独HTMLからサーバーのフォルダを選択することはできません。通常モードの「手元の音声」「手元の軌跡CSV」は従来通りブラウザ側のPCを参照します。ファイルを選び直して読み込むとプレイヤーは作り直され、再生位置や表示設定は初期化されます。

読み込んだプレイヤーは `browser.player` に保存され、`browser.player.save("sync_player.html")` でHTML出力できます。

ウィジェットが文字列のまま表示される場合はJupyter側のウィジェット機能を確認してください。JupyterLabとカーネルが別環境なら、カーネル側に `ipywidgets`、JupyterLab側に `jupyterlab_widgets` が必要です（[公式インストール手順](https://ipywidgets.readthedocs.io/en/stable/user_install.html)）。

[example.ipynb](example.ipynb) に添付サンプルを使う例があります。別の場所から起動する場合は、リポジトリのルートを `sys.path` に追加してください。

Notebookに表示されない場合は、そのNotebookを信頼済みにしてください。表示環境がiframe内のJavaScriptや音声再生を制限する場合は、次のHTML出力を使ってください。

## 単独HTMLとして使う

```python
player.save("sync_player.html")
```

HTMLをChrome、Edge、Safari、Firefox等のブラウザで開きます。Python環境は不要です。音声・CSVはHTML内に埋め込まれるため、保存ファイルには元データが含まれます。データは外部へ送信しません。大きな録音ではHTMLとNotebookの出力サイズも大きくなるため、空のプレイヤーで画面からファイルを選ぶ使い方が便利です。

## 操作

- **再生 / 一時停止・先頭へ・シークバー**：音声と3図を同期。波形やスペクトログラムのクリックでもシークできます。
- **Ch**：入力チャンネルごとの波形・スペクトログラム・試聴を切り替えます。試聴は選択チャンネルのモノラル、全Ch平均は全入力チャンネルの平均です。すべての入力でCh 1を初期選択し、チャンネル平均は明示的に選んだ場合のみ使います。
- **通常 / メル**：表示欄で通常のHzスペクトログラムと、128帯域のメルスペクトログラムを切り替えます。FFTは共通で、波形データ・再生・拡大範囲は変えません。メルはHTK式 `2595 log10(1 + f/700)` の等間隔な三角フィルタ（0〜Nyquist、128帯域、面積正規化なし）で線形パワーを合算し、`10 log10(power)` を表示します。単に周波数目盛りを変更する方式ではありません。縦軸はメル間隔で、ラベルは対応するHzです。メルのdBは基準パワー1であり、通常表示の各FFTビンの振幅dBFSと同じ値にはなりません。
- **カラーマップ**：スペクトログラムの既定は `jet`。`viridis`、`gray`、`warm`（従来の配色）に切り替えられます。再生中も時刻や拡大範囲を維持して即座に反映します。
- **dB範囲・カラーバー**：下限・上限（通常: dBFS、メル: dB ref=1）を入力して「適用」（またはEnter）で変更します。既定は−100〜0。スペクトログラム下のカラーバーに、選択中の配色と対応するdB値を表示します。下限以下は最小色、上限以上は最大色です。下限は上限より小さくしてください。再生位置・拡大範囲を保ち、FFTの再計算なしで反映します。
- **現在座標**：現在位置の丸印のそばにIDと、表示している2軸の列名・座標値（小数点以下3桁）を重ねます。座標値も再生・シークに追従します。
- **速度・音量**：再生速度は0.5〜2倍。速度を変えると音高も変わります。
- **ホイール**：カーソル位置を中心に拡大・縮小。波形とスペクトログラムは時間範囲を共有します。
- **ドラッグ**：時間方向または軌跡平面を移動します。
- **拡大**：各図を全画面表示。Escで戻ります。Notebookの制約で使えない場合は単独HTMLを開いてください。
- **表示リセット / ダブルクリック**：全体表示に戻します。
- **CSVの列・時刻合わせ**：時刻・人物ID・区間ID・X/Yの列を変更し、「設定を適用」を押します。Yを `z_m` にすればXZ平面も確認できます。

## 入力形式と同期

音声はWAV、MP3、FLAC等、利用ブラウザのWeb Audioデコーダーが対応する形式を使用できます。ブラウザでデコードできない形式・コーデックはWAV等に変換してください。全音声をメモリに読み込みます。

**波形・解析に使うデータ**：PCM WAV（8/16/24/32bit整数、32/64bit浮動小数、対応するWAVE_FORMAT_EXTENSIBLE）はRIFF内のサンプルを直接読み、元の周波数・サンプル数・順序を保持します。整数PCMはフルスケール1に換算し、内部はFloat32で保持します（32bit整数・64bit浮動小数では精度丸めが生じます）。リサンプリング、平滑化、フィルタ、ピーク正規化はしません。FLACはSTREAMINFOの元周波数を指定したOfflineAudioContextでデコードします。その他の形式（MP3等）はブラウザデコードで周波数変換が発生する可能性があり、画面にその旨を表示します。

**再生出力**：出力機器の周波数が表示・解析データと異なる場合、ブラウザが再生時に変換します。これは解析データを変更しません。画面に表示・解析の周波数とサンプル数、再生出力の周波数を分けて表示します。

旧実装では `AudioContext.decodeAudioData` により、WAVも出力側の周波数へ変換されていました。現在のPCM WAV直接読み込みはこの経路を通りません。

CSVはUTF-8（BOMあり・なし）、カンマ区切り、ヘッダー付きです。次の列名を自動認識します。異なる名前でも画面から指定できます。

| 内容 | 自動認識する列（左から優先） |
| --- | --- |
| 時刻 | `clip_time_s`, `time_s`, `timestamp`, `time`, `t`, `datetime`, `original_time_s` |
| 人物ID（任意） | `source_id`, `person_id`, `agent_id`, `track_id`, `id` |
| 区間ID（任意） | `segment_id`, `segment` |
| X座標 | `x_m`, `x`, `pos_x`, `position_x` |
| Y座標 | `y_m`, `y`, `pos_y`, `position_y` |

時刻は秒単位の数値、またはブラウザが解釈できる日時（タイムゾーン付きISO 8601推奨）。フレーム番号やミリ秒は事前に秒へ変換してください。座標は入力単位をそのまま使い、X/Yの縮尺は同一です。IDなしでは1本の軌跡として扱います。

**音声時刻 = CSV時刻 + オフセット**。添付サンプルは `clip_time_s` とオフセット0で同期します。例えばCSVが録音の548.8秒地点を起点に切り出され、時刻が548.8から始まる場合は、オフセットに `-548.8` を指定します。日時を使う場合も録音開始のUNIX秒の負値で合わせられます。

全経路を薄線で描き、区間内の現在位置を線形補間して丸印とID・現在の座標値を重ねます。各区間の開始前・終了後には丸印を出しません。別の区間ID間や、設定した最大間隔を超える欠測区間は線でつながず、位置も補間しません。最大間隔の初期値は同一区間内のサンプリング間隔の中央値の3倍です。同一区間・同時刻の重複は最後の行を採用し、無効な座標・時刻の行は除外して件数を表示します。

スペクトログラムは2048点FFT、Hann窓、片側振幅のdBFS表示です（表示範囲の初期値は−100〜0、画面から変更可能）。時間列数を最大1800程度に抑えており、長い録音を拡大してもスペクトログラム自体の時間分解能は増えません。波形は表示ピクセルごとの最小・最大値を描き、短いピークを保持します。波形の縦軸は選択チャンネルのピークに合わせて自動調整します（試聴音量は変えません）。

## 検証

```sh
python -m unittest discover -s gui/tests
```

実ブラウザの追加検証（6秒を超える音声、有効な軌跡CSV、Chrome、`websocket-client` が必要）:

```sh
python -m gui.tests.browser_smoke /path/to/audio.wav /path/to/trajectory.csv
```

macOS以外では `--chrome /path/to/chrome` で実行ファイルを指定できます。読み込み、再生時計、再生中のシーク、チャンネル変更、CSV引用符、欠測補間、ズーム、終端停止、カラーマップ変更、dB表示範囲とカラーバーの連動・入力検証、現在座標の重畳表示、メルフィルタのパワー集計、PCM16 WAVの全チャンネル全サンプルの一致を確認します。
